# Welcome to DeDi.global

{% hint style="success" icon="file-signature" %}
**Protocol v2 — publish files, you're on the network.** No server to run, no account to create: sign your files, serve them on your own domain, and dedi.global crawls and indexes them. [Publishing guide →](resources/publishing-dedi-files/)
